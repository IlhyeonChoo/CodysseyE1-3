## 데이터 사실(검증 완료)

- 행 우선 `+=`, epsilon 1e-9 기준으로 총 6건, 통과 3건, 실패 3건이다.
  - 실패는 `size_5_1`, `size_13_2`, `size_25_1`이고 모두 UNDECIDED다.
  - 정확한 값은 동점이다(9/10, 15/2, 49/10).
  - 행 우선 `+=`로 누적한 뒤 epsilon 없이 `>`로 비교하면 세 건 모두 expected와 반대 라벨이 나온다. 각 점수의 0이 아닌 항은 한 개이거나 같은 수의 반복이어서 역순·열 우선으로 순회해도 같은 값이 나온다. 보정 합산을 쓰면 계산된 점수 차이가 달라질 수 있다.
- Python 3.12의 `sum()`은 보정 합산을 써서 동점 3건을 정확히 같은 값으로 만든다. 명시적 `+=`는 3.11과 3.12에서 결과가 같다.
- data.json 최상위 키는 `meta`, `filters`, `patterns`다. 분석에는 `filters`와 `patterns`를 사용한다.
- 패턴 input 6개는 다음 규칙과 정확히 일치한다. 필터는 가중치형이라 이 규칙과 다르다.
  - Cross: 가운데 행·열
  - X: 두 대각선
- 최초 점검의 로컬 측정 기록이다. 당시 clocksource는 hpet이었고 `perf_counter()` 1회 호출 비용은 약 1.4 µs였다. 다음 시간 수치는 실행 환경에 따라 달라진다.
  - 호출당 MAC 시간: 3×3 약 0.0007 ms(구간 측정)에서 0.002 ms(호출별 측정)
  - 25×25/3×3 시간 비: 약 10배(호출별 측정), 약 27~30배(구간 측정). 연산 비는 69.4배다.
- 모드 1 동점 재현 입력: A=`0.9 0 0 / 0 0 0 / 0 0 0`, B=전부 0.1, 패턴=전부 1. 결과는 0.9 대 0.8999999999999999다.
