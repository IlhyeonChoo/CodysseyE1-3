# 모드별 기능

## 모드 1

- 3x3 필터 X와 십자가 입력 받기
- 3x3 패턴 입력 받기
- 입력 형태 검증
- 연산
- 연산 결과 출력 (점수, 판정, 연산 시간, 연산 횟수)

## 모드 2

- data/data.json 에서 로드
- 로드된 patterns에 N값 추출하여 적절한 사이즈의 필터 선택
- 필터와 패턴 검증(비정상 종료 X)
- 각 pattern 결과 출력

# 공통(utils)

- 필터와 패턴 세팅
  입력 받은 값 또는 data에서 로드한 값 하나의 객체로 생성
- 패턴과 필터 검증
  그냥 2개가 맞나? 입력 받은 경우 입력시 패턴이 라벨링된 값이라는 보장이 없네
  근데 입력은 N=3 로드는 N의 값 가져와서 같은 함수에 넣는게 좋을듯?
- 연산 및 연산 횟수 계산
- 시간 계산
- 점수 비교
